The terminal is a design surface

2026-01-19 · tools

We talk about the terminal as a constraint — eighty columns, a fixed grid, a handful of colors. But a constraint is just a canvas with strong opinions. The grid is a layout engine. The monospace cell is a unit you can actually trust.

Box-drawing characters are a vector library. ANSI color is a palette. The cursor is an animation primitive. Once you stop apologizing for the medium, it turns out to be one of the most honest design surfaces we have.
